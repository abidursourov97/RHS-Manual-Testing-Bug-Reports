# RHS – Manual Testing Bug Reports

## Project Overview

This repository contains manual testing bug reports and QA findings for the **RHS** platform. The testing focused on identifying functional issues, UI/UX inconsistencies, workflow problems, validation errors, and usability concerns across multiple modules of the application.

# Types of Testing Performed

## Functional Testing

Validated whether application features work according to expected business requirements.

## UI/UX Testing

Checked alignment, visibility, spacing, responsiveness, and usability of UI components.

## Regression Testing

Verified that existing functionalities continued working after updates or fixes.

## Workflow Testing

Tested complete user flows including login, ordering, cart operations, and account-related actions.

# Bug Report Structure

The Excel reports include:

| Column             | Description                  |
| ------------------ | ---------------------------- |
| Module             | Feature/module being tested  |
| Test Case          | Testing scenario             |
| Expected Result    | Intended system behavior     |
| Actual Result      | Observed behavior            |
| Reproduction Steps | Steps to reproduce the issue |
| Severity/Priority  | Bug impact level             |
| Screenshot         | Visual evidence              |
| Status             | Current bug status           |
